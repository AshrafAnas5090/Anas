# مساحة أنس التعليمية

هذا الموقع جاهز للنشر على GitHub Pages. يحتوي `index.html` على البرنامج والصور المضمّنة، فلا يحتاج ملفات تشغيل إضافية.

## رفع الملفات

1. أنشئ مستودع GitHub جديدًا.
2. ارفع `index.html` و`README.md` و`ATTRIBUTION.md` إلى جذر المستودع.
3. من إعدادات المستودع افتح **Pages**، ثم اختر النشر من فرع `main` ومجلد `/(root)`، واحفظ الإعداد.
4. افتح رابط Pages الذي يظهر في الإعدادات.

الملف يعمل مباشرة عند فتحه في متصفح حديث. تعمل الصوتيات بحسب دعم المتصفح لميزة النطق.

المحتوى يشمل ست وحدات إنجليزية أساسية، وقائمة قراءة عربية من 110 كلمات، منها 50 كلمة مألوفة جديدة، مع الجرامر والمواد الأخرى الموجودة في النسخة.
